# AGENTS.md — Manager app (Flutter, Android)

Read the root `AGENTS.md` first.

## Before touching any screen

| Order | Open | For |
|---|---|---|
| 1 | `docs/design/prototype.html` | **The approved design. Open it in a browser.** This is the truth — the spec below is a description of it |
| 2 | `docs/product/UI_SPEC.md` §3–§4 | Layout rules, the three critical screens, component list |
| 3 | `docs/design/SCREENS.md` | Whether this screen is even in v1.0 |

**The design is done. Do not redesign.** If the prototype and the spec
disagree, the prototype wins — and say so, so the spec gets corrected.

**Except on architecture and auth, where an accepted ADR outranks the
prototype.** The prototype is a design artifact; it was drawn before some
decisions were made. Two live conflicts you will hit:

| Prototype shows | Build instead | Why |
|---|---|---|
| Phone → 4-digit OTP sign-in | **Google Sign-In** (Firebase), phone as a profile field | ADR-0009. OTP needs an SMS gateway and tempts `READ_SMS`, which triggers a Play permissions review |
| 5 bottom-nav tabs (হোম · মিল · হিসাব · সদস্য · আরও) | **4 tabs** — আজ · খাতা · হিসাব · আরও, with সদস্য under আরও | UI_SPEC §2. সদস্য is a setup-time screen, not a daily one |

If you find a third conflict, stop and raise it. Do not resolve it yourself.

## Layout

```
lib/
  main.dart           entrypoint
  app.dart            bottom-nav shell ← navigation lives here.
                      Exactly 4 tabs in v1.0. Adding a fifth is a scope
                      change, not a UI change — raise it first.
  core/
    theme/tokens.g.dart   ★ GENERATED by `make tokens` — never edit
    i18n/                 ARB files, bn is the source of truth
    api/                  generated Dart models + thin HTTP transport
    widgets/              shared components (UI_SPEC §5)
  features/
    onboarding/ today/ grid/ members/ accounts/ close/ settings/
```

## Non-negotiables — `make verify` fails on these

- **No hardcoded user-visible strings.** Every one is an ARB key.
- **No hardcoded colours.** Import `TinBelaColors` from `tokens.g.dart`.
- **No money arithmetic in widgets.** Render the `MathExplain` the API sent.
  An arithmetic operator near a paisa variable is a bug.
- Touch targets ≥ 48dp. Glare and one-handed use, not a style preference.

## Product rules that look like style but are not

- **A zero-exception day must look FINISHED, not empty.** The line
  "বাকি সবাই ডিফল্ট প্যাটার্নে ✓ / কিছু করার নেই" is the product stated in
  words. Do not soften or remove it.
- Nothing above the fold on Today except the cutoff card and two buttons.
- Confirmation is a toast. Dialogs only for irreversible actions.
- Voids say "বাতিল হলো" and keep the original visible. Never
  "মুছে ফেলা হয়েছে" — append-only is a promise to the user, not just schema.
- No spinner without a skeleton. No error without a retry. Mess wifi is bad
  and users blame the app, not the network.
- **No dead rows in আরও.** The prototype's আরও menu shows রুম/সিট,
  ক্লিনিং রোটা, খালা/বাবুর্চি, মাস কিনুন and পেমেন্ট লিংক. All are P2/P3/P5
  (`docs/design/SCREENS.md`). In v1.0 they are **absent**, not greyed out and
  not "coming soon" — a Play reviewer opens every row, and a dead end reads as
  an unfinished app.
- **No ad slots rendered in v1.0.** Reserve the layout space so the P5 drop-in
  does not reflow Today, but ship nothing in it.

## Bangla

bn is the source of truth; en is the translation. The voice is **a friend
who is good at maths**, not a bank.

- YES: "কিছু করার নেই" · "হিসাব শেষ, আপনি মুক্ত"
- NO:  "কোনো কার্যক্রম সম্পাদনের প্রয়োজন নেই"

Test every screen at 130% system text size. Bangla script overflows
fixed-height rows — the most common visual bug in Bangladeshi apps.

## Performance

60fps on a 4-year-old mid-range Android. No blur, one shadow elevation, no
heavy animation, `const` everywhere possible, lazy lists.

## Transport

Generated Dart protobuf models over plain HTTP/JSON against Connect's JSON
codec (ADR-0003). Do **not** add a Connect Dart client dependency.
